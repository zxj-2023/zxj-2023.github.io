anthropic 原生 web_search 的真实机制

看 anthropic.py:134-149，pig-mono 的处理方式是：

def _resolve_tools_with_web_search(self, kwargs: dict) -> list[dict] | None:
    """Build the Anthropic tools list from function tools + optional native search."""
    enable_web = kwargs.pop("enable_web_search", False)   # ← 从 kwargs 弹出统一开关
    max_uses = kwargs.pop("web_search_max_uses", 5)
tools = ...  # 你的 function tools 转成 anthropic 格式

if enable_web:
    tools.append({                                  # ← 追加 anthropic 原生搜索工具
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": max_uses,
    })
return tools

关键事实：anthropic 的 web_search 不是一个独立 API 调用，而是在 tools 列表里追加一个内置工具 {“type”: “web_search_20250305”, “name”: “web_search”}。模型判断需要搜索时，服务端执行搜索并把结果合进响应（不是返回 tool_calls 让你执行）。你什么都不用做，拿到 Response 就是带搜索结果的回答。

你的统一 LLM.chat() 收 tools: list[dict]。要让 anthropic provider 支持原生搜索，在 anthropic provider 内部处理（anthropic.py）：

AnthropicProvider.complete / stream 里

def _resolve_tools(self, tools, kwargs):
    # 1. 从 kwargs 弹出统一开关（openai/deepseek 会忽略它，自然不传）
    enable_web = kwargs.pop("enable_web_search", False)
    max_uses = kwargs.pop("web_search_max_uses", 5)
    
# 2. 你的 function tools 转成 anthropic 格式
anthropic_tools = convert_to_anthropic(tools) if tools else []

# 3. 开关打开就追加原生搜索工具
if enable_web:
    anthropic_tools.append({
        "type": "web_search_20250305",
        "name": "web_search",
        "max_uses": max_uses,
    })
return anthropic_tools
